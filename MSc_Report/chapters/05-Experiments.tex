\section{Measuring the Robustness of Projection Differences}
\label{sec:robustness}
RQ1 asked about how robust projection differences are to subsequent fine-tuning. Quantifying this potential decay is important in practice as it allows us to assess how much confidence we can assign to a given prediction. Intuitively, the more fine-tuning updates are conducted, the more likely the behaviour predictor computed at step 0, $f_0$, is to have increased its error. Thus, quantifying the decay in the predictive power of projection differences can help establish thresholds after which the behaviour predictor gets updated. This is important, as recalibrating the predictor model can be costly; generating the training data requires computing the projection difference for a set of datasets, training on them, and evaluating the model's behaviour afterwards.

Therefore, for projection differences to be useful in a continual learning setting, they need to remain well calibrated for as many training events as possible. In this section, we describe the experiments to validate how accurate a linear model calibrated at time 0 using $\Delta P_0$ and $b_t$ pairs remains after subsequent fine-tunings. 

To study this robustness, we first evaluate the predictive power of each projection difference variant presented in \Cref{sec:deltap-variants}.

\section{Out-of-Sample Forecasting}

The correlations above are measured by fitting a line to the very checkpoint
they describe, which answers whether a relationship survives but not whether a
practitioner could use it. Nobody who has paid for a fan-out at the initial model
repeats it at every step; they carry $M_0$'s line forward and read a prediction
off it. Figure~\ref{fig:recalibration-grid} shows one affine map per trait,
fitted once on the 16 validation datasets that are \emph{not} probes and
applied unchanged at every later checkpoint. The tables and
Figure~\ref{fig:forecast-grid} instead use leave-one-dataset-out predictions:
each probe is predicted by a line fitted on the other 23 validation datasets.

A correlation cannot report this. Pearson $r$ is invariant under a fixed affine
map, so scoring $M_0$'s predictions by correlation would reproduce
Table~\ref{tab:decay-correlations} cell for cell. What a frozen predictor loses
is its calibration, not its ordering, and calibration is only visible in an
error. Every number below is therefore an error on the judge's own 0--100
scale, and smaller is better --- the reverse of the tables above.

\subsection{Out-of-Sample Evaluation}
\label{sec:gain-evaluation}

We evaluate the correction using two-dimensional cross-validation. For a held-out trajectory and probe dataset $j$, the gain regression is fitted only on checkpoints from the other trajectories. Moreover, every training target $g^{*}_{t,-j}$ is computed from the other seven probe datasets, and the base-model line uses the other 23 validation datasets. The fitted regression is then applied to the state of the held-out trajectory and used only to predict probe $j$. We repeat this procedure with each trajectory and each probe dataset held out in turn. Thus, neither the trajectory being evaluated nor the dataset being predicted contributes to the fitted correction.

Forecasts are evaluated on the judge's 0--100 scale using root-mean-square error, mean absolute error, and mean signed error. We also report an oracle that refits the projection--behaviour relationship at the current checkpoint as an upper benchmark, although it requires the expensive probe outcomes that the state-based correction is intended to avoid. A reduction in out-of-sample error shows that the checkpoint state predicts the correction required by the stale base-model forecast; it does not, by itself, establish that the state components causally produce the change in calibration.
