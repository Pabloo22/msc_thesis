RQ1 asked about how robust projection differences are to subsequent fine-tuning. Quantifying this potential decay is important in practice as it allows us to assess how much confidence we can assign to a given prediction. Intuitively, the more fine-tuning updates are conducted, the more likely the behaviour predictor computed at step 0, $f_0$, is to have increased its error. Thus, quantifying the decay in the predictive power of projection differences can help establish thresholds after which the behaviour predictor gets updated. This is important, as recalibrating the predictor model can be costly; generating the training data requires computing the projection difference for a set of datasets, training on them, and evaluating the model's behaviour afterwards.

Therefore, for projection differences to be useful in a continual learning setting, they need to remain well calibrated for as many training events as possible. In this chapter, we describe the experiments to validate how accurate a linear model calibrated at time 0 using $\Delta P_0$ and $b_t$ pairs remains after subsequent fine-tunings. We also investigate whether the dynamic calibration mechanism described in \Cref{sec:dynamic-recalibration} helps mitigate this decay.

\subsection{Do Projection Differences Require Calibration?}
In the previous section, we studied whether projection differences remain useful tools to predict the behaviour of a model after fine-tuning. However, in practice, we cannot train on 8 probe datasets after every step to fit the linear model that maps projection differences to behaviour, since it is computationally more expensive than simply fine-tuning the model on the next dataset. Thus, we need to fit this linear predictor at step 0, and carry their predictions forward to later checkpoints as we mentioned in \Cref{sec:dynamic-recalibration}.

We evaluate the correction using two-dimensional cross-validation. For a held-out trajectory and probe dataset $j$, the recalibration-factor regression is fitted only on checkpoints from the other trajectories. Moreover, every training target $c^{*}_{t,-j}$ is computed from the other seven probe datasets, and the base-model line uses the other 23 validation datasets. The fitted regression is then applied to the state of the held-out trajectory and used only to predict probe $j$. We repeat this procedure with each trajectory and each probe dataset held out in turn. Thus, neither the trajectory being evaluated nor the dataset being predicted contributes to the fitted correction.

Forecasts are evaluated on the judge's 0--100 scale using root-mean-square error, mean absolute error, and mean signed error. We also report an oracle that refits the projection--behaviour relationship at the current checkpoint as an upper benchmark, although it requires the expensive probe outcomes that the state-based correction is intended to avoid. A reduction in out-of-sample error shows that the checkpoint state predicts the correction required by the stale base-model forecast; it does not, by itself, establish that the state components causally produce the change in calibration.

\section{Experiment 2: History Dependence}
\label{sec:hysteresis}
In this experiment, we investigated whether a previously misaligned model is more prone to future misalignment. Concretely, we ran four types of trajectories, all of which end on the same trait-eliciting dataset $X$ but differ in what came before it. The four types are the following:
\begin{itemize}
    \item $X$: the initial model is fine-tuned on $X$.
    \item $N\ X$: the model is first fine-tuned on a normal dataset, and then on $X$.
    \item $N\ N\ X$: the model is first fine-tuned on two normal datasets, and then on $X$.
    \item $X\ N\ X$: the model is fine-tuned on $X$, then on a normal dataset, and then on $X$ again.
    \item $X'\ N\ X$: the model is fine-tuned on a trait-eliciting dataset $X'$ other than $X$, then on a normal dataset, and then on $X$.
\end{itemize}
