\section{Neural Networks}
\label{sec:neural_networks}

Before discussing transformers and large language models, it is useful to briefly introduce the neural networks on which they are built. Deep learning refers to a family of machine-learning methods in which multiple processing layers learn increasingly abstract representations of the input \citep{lecun2015deep_learning}. For example, in a language model, early layers may encode local information about individual tokens, while later layers combine this information into representations that depend on the surrounding context. Unlike approaches that rely on manually designed features, these representations are learned from data together with the final prediction rule.

The basic component of a neural network is an artificial neuron. Given an input vector $\mathbf{x} \in \mathbb{R}^{d}$, a neuron first computes an affine transformation and then applies a nonlinear activation function:
\begin{equation}
    h = \sigma(\mathbf{w}^{\top}\mathbf{x} + b),
    \label{eq:artificial_neuron}
\end{equation}
where $\mathbf{w} \in \mathbb{R}^{d}$ is a vector of learnable weights, $b \in \mathbb{R}$ is a learnable bias, and $\sigma$ is the activation function. A common choice is the rectified linear unit (ReLU), defined as $\operatorname{ReLU}(z)=\max(0,z)$ \citep{glorot2011deep_sparse_rectifier}. The nonlinearity is essential: without it, composing several layers would still be equivalent to applying a single affine transformation, regardless of the number of layers.

Neurons are organized into layers to form a neural network. The simplest example is a multilayer perceptron, in which every unit in one layer is connected to every unit in the following layer. Let $\mathbf{h}^{(0)}=\mathbf{x}$ denote the input. The representation produced by layer $l$ is
\begin{equation}
    \mathbf{h}^{(l)} = \sigma^{(l)}\!\left(\mathbf{W}^{(l)}\mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}\right),
    \qquad l=1,\ldots,L,
    \label{eq:feedforward_layer}
\end{equation}
where $\mathbf{W}^{(l)}$ and $\mathbf{b}^{(l)}$ are the layer's weight matrix and bias vector, respectively. The vectors $\mathbf{h}^{(1)},\ldots,\mathbf{h}^{(L-1)}$ are called hidden representations or activations. The final layer produces the network's prediction, and its precise form depends on the task. For example, a classifier can transform its final output into a probability distribution over classes using the softmax function.

The term ``deep'' indicates that the network contains multiple successive layers. Each layer operates on the representation generated by the previous one, allowing the network to build a hierarchy of features \citep{lecun2015deep_learning}. This composition is particularly important in this project because the behaviour of a language model depends not only on its learned parameters but also on the intermediate activations produced when it processes a prompt. Later sections use directions in this activation space to represent and measure behavioural traits.

Training consists of selecting the network parameters so that its predictions fit a dataset. Let $f_{\boldsymbol{\theta}}$ denote a network containing all weights and biases in the parameter vector $\boldsymbol{\theta}$, and let $\mathcal{D}=\{(\mathbf{x}_i,\mathbf{y}_i)\}_{i=1}^{N}$ be a supervised training dataset. The usual objective is to minimize the empirical loss
\begin{equation}
    \mathcal{L}(\boldsymbol{\theta})
    = \frac{1}{N}\sum_{i=1}^{N}
    \ell\!\left(f_{\boldsymbol{\theta}}(\mathbf{x}_i),\mathbf{y}_i\right),
    \label{eq:empirical_loss}
\end{equation}
where $\ell$ measures the discrepancy between a prediction and its target. Common examples include mean squared error for regression and cross-entropy for classification. Although language modelling uses a particular form of cross-entropy introduced in \Cref{sec:large_language_models}, the same optimization principle applies.

The gradient of this loss with respect to every parameter is computed efficiently using backpropagation \citep{rumelhart1986backpropagation}. Backpropagation applies the chain rule from the output layer towards the input, reusing intermediate derivatives rather than calculating the effect of each parameter independently. An optimizer then uses these gradients to update the parameters. In its simplest form, gradient descent performs
\begin{equation}
    \boldsymbol{\theta}_{t+1}
    = \boldsymbol{\theta}_{t} - \eta\nabla_{\boldsymbol{\theta}}
    \mathcal{L}(\boldsymbol{\theta}_{t}),
    \label{eq:gradient_descent}
\end{equation}
where $t$ is the optimization step and $\eta>0$ is the learning rate. In practice, the gradient is generally estimated using a small batch of training examples, producing stochastic gradient descent. Adaptive optimizers such as Adam additionally maintain moving estimates of the gradient's first and second moments to scale parameter updates \citep{kingma2015adam}.

Once trained, the network performs inference by applying only the forward computations in \Cref{eq:feedforward_layer}. Training, by contrast, changes the parameters and therefore can change both the network's predictions and the internal representations from which those predictions are produced. This distinction between parameters, activations, and observable behaviour will be central when analysing how sequential fine-tuning changes a language model.

\section{Transformers}
\label{sec:transformers}

The multilayer perceptron introduced above assumes that its input has a fixed size and does not explicitly represent relationships between elements in a sequence. Language, however, has a variable length, and the meaning of a token often depends on tokens that may be far away from it. Transformers address this problem using self-attention, a mechanism that allows every token representation to gather information from other relevant positions in the sequence \citep{vaswani2017attention}.

Before being processed by a transformer, a sequence of $n$ tokens is mapped to a matrix $\mathbf{X} \in \mathbb{R}^{n \times d_{\mathrm{model}}}$. Each row of $\mathbf{X}$ is the vector representation, or embedding, of one token. Because self-attention alone does not encode token order, positional information must also be incorporated into the computation. This can be done by adding a positional encoding to each token embedding or by modifying the attention operation itself. The resulting activations can therefore represent both which tokens are present and where they occur in the sequence.

The central idea behind self-attention is that the representation required at one position depends on the current token's relationship with the other tokens. To model these relationships, the input is projected into three matrices known as queries, keys, and values:
\begin{equation}
    \mathbf{Q}=\mathbf{X}\mathbf{W}_{Q}, \qquad
    \mathbf{K}=\mathbf{X}\mathbf{W}_{K}, \qquad
    \mathbf{V}=\mathbf{X}\mathbf{W}_{V},
    \label{eq:qkv_projections}
\end{equation}
where $\mathbf{W}_{Q}$, $\mathbf{W}_{K}$, and $\mathbf{W}_{V}$ are learned projection matrices. Intuitively, a query represents the information that a token is looking for, a key represents the information that another token makes available for matching, and a value contains the information that will be passed forward if that token is attended to.

Scaled dot-product attention is then calculated as
\begin{equation}
    \operatorname{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V})
    = \operatorname{softmax}\!\left(
        \frac{\mathbf{Q}\mathbf{K}^{\top}}{\sqrt{d_k}} + \mathbf{M}
      \right)\mathbf{V},
    \label{eq:scaled_dot_product_attention}
\end{equation}
where $d_k$ is the dimension of each key and $\mathbf{M}$ is an optional attention mask. The product $\mathbf{Q}\mathbf{K}^{\top}$ contains a score for every pair of token positions. Dividing by $\sqrt{d_k}$ prevents these dot products from growing too large as their dimension increases, while the row-wise softmax converts the scores into non-negative weights that sum to one. Each output row is therefore a learned weighted average of the value vectors.

Transformers use multiple attention heads in parallel. Each head has its own query, key, and value projections, allowing different heads to capture different relationships between tokens. Their outputs are concatenated and projected back to the model dimension:
\begin{equation}
    \operatorname{MultiHead}(\mathbf{X})
    = \operatorname{Concat}(\operatorname{head}_1,\ldots,
      \operatorname{head}_H)\mathbf{W}_{O},
    \label{eq:multi_head_attention}
\end{equation}
where $H$ is the number of heads, $\mathbf{W}_{O}$ is another learned matrix, and each $\operatorname{head}_h$ applies \Cref{eq:scaled_dot_product_attention} with its own projections. The role learned by an individual head is not fixed beforehand; it emerges during training.

An attention operation is followed by a position-wise feed-forward network, which applies the same multilayer perceptron independently to every token position. Residual connections pass each sublayer's input directly to its output, while layer normalization helps stabilize the sequence of transformations. Stacking these blocks produces progressively contextualized activations: after each layer, a token vector contains information not only about that token but also about the other positions to which it attended.

The original transformer contains an encoder, which processes an input sequence, and a decoder, which generates an output sequence \citep{vaswani2017attention}. Most autoregressive large language models instead use a decoder-only architecture. In this setting, the mask $\mathbf{M}$ in \Cref{eq:scaled_dot_product_attention} assigns $-\infty$ to positions in the future. After the softmax, those positions receive zero attention weight. Consequently, the representation at position $t$ can depend only on tokens at positions $1,\ldots,t$, preventing the model from accessing the answer that it is being trained to predict.

Self-attention is particularly relevant to the mechanistic analysis in this project. At every transformer layer and token position, the model produces a vector in its activation space. The activation of the final prompt token summarizes information gathered from the preceding context and is the representation later projected onto persona directions. Fine-tuning can change this representation by modifying the weights that produce queries, keys, values, and feed-forward transformations.

\section{Large Language Models}
\label{sec:large_language_models}

A language model assigns probabilities to sequences of text. Contemporary large language models (LLMs) are neural language models with a large number of parameters, trained on large text corpora using substantial computational resources. There is no universally agreed parameter threshold at which a language model becomes ``large''; the term instead describes the scale of the model and its training relative to earlier systems. The models considered in this project are autoregressive, decoder-only transformers.

Since neural networks operate on vectors rather than raw text, a tokenizer first divides the text into discrete tokens from a fixed vocabulary. Tokens often correspond to subwords rather than complete words, allowing a limited vocabulary to represent common words efficiently while still composing rare or unseen words from smaller units \citep{sennrich2016subword}. Each token is assigned an integer identifier and then mapped to the embedding vector used as input to the transformer. Tokenization is therefore part of the model definition: changing the tokenizer changes the sequences on which the model is trained and evaluated.

Let $x_{1:T}=(x_1,\ldots,x_T)$ denote a sequence of tokens. Using the chain rule of probability, an autoregressive language model factorizes the probability of the sequence as
\begin{equation}
    p_{\boldsymbol{\theta}}(x_{1:T})
    = \prod_{t=1}^{T}
      p_{\boldsymbol{\theta}}(x_t \mid x_{<t}),
    \label{eq:autoregressive_factorization}
\end{equation}
where $x_{<t}=(x_1,\ldots,x_{t-1})$ is the preceding context. At position $t-1$, the final transformer activation is multiplied by an output matrix to produce one logit for every token in the vocabulary. Applying a softmax to these logits gives the conditional distribution $p_{\boldsymbol{\theta}}(x_t \mid x_{<t})$.

During pre-training, the model learns to predict tokens from a large collection of text. Its parameters are optimized by minimizing the negative log-likelihood, equivalently the cross-entropy loss,
\begin{equation}
    \mathcal{L}_{\mathrm{LM}}(\boldsymbol{\theta})
    = -\sum_{t=1}^{T}
      \log p_{\boldsymbol{\theta}}(x_t \mid x_{<t}).
    \label{eq:language_model_loss}
\end{equation}
Every position in a training sequence can provide a prediction target in parallel because the causal attention mask prevents information from future positions from leaking backwards. By applying this objective across a broad corpus, a model can acquire linguistic patterns and information that support many downstream tasks \citep{brown2020language_models}.

At inference time, the model is given a prompt and predicts a distribution for the next token. A decoding rule selects or samples a token from this distribution, appends it to the context, and repeats the process until a stopping condition is reached. Greedy decoding always selects the most probable token, whereas stochastic decoding can produce different responses to the same prompt. Importantly, this form of in-context adaptation changes the activations produced from the current context but does not update the model parameters.

Pre-training teaches a model to continue text, but it does not by itself ensure that the model will reliably follow user instructions. Instruction-tuned models undergo additional training on examples that pair prompts with desired responses. In supervised fine-tuning, the next-token objective in \Cref{eq:language_model_loss} is applied to these demonstrations, commonly with the loss restricted to tokens in the target response. Further preference-based training may then be used to make outputs more helpful and safe \citep{ouyang2022instructgpt}. Thus, an instruction-tuned LLM is not trained from scratch for each task; it begins with capabilities acquired during pre-training and its behaviour is subsequently adapted using more targeted data.

Fine-tuning can update every parameter in the model, but doing so is expensive for an LLM. Parameter-efficient fine-tuning methods instead train a much smaller set of additional parameters. This project uses low-rank adaptation (LoRA), which freezes a pre-trained weight matrix $\mathbf{W} \in \mathbb{R}^{d_{\mathrm{out}} \times d_{\mathrm{in}}}$ and represents its update as the product of two smaller matrices \citep{hu2022lora}:
\begin{equation}
    \mathbf{W}' = \mathbf{W} + \Delta\mathbf{W}
    = \mathbf{W} + \frac{\alpha}{r}\mathbf{B}\mathbf{A},
    \label{eq:lora_update}
\end{equation}
where $\mathbf{A} \in \mathbb{R}^{r \times d_{\mathrm{in}}}$, $\mathbf{B} \in \mathbb{R}^{d_{\mathrm{out}} \times r}$, and the rank $r$ is much smaller than either original dimension. Only $\mathbf{A}$ and $\mathbf{B}$ are optimized, while $\alpha/r$ controls the scale of the update. LoRA can be applied, for example, to the projection matrices in the attention mechanism, thereby changing how token information is read and combined without directly training the full base model.

The distinction between pre-training, inference, and fine-tuning is fundamental to this work. Pre-training produces the initial model, inference reveals its behaviour and internal activations, and each fine-tuning dataset causes a parameter update that may alter both. Sequential fine-tuning repeats this last operation, producing a trajectory of related models rather than a single fixed system. The central question of this thesis is whether activation-space measurements made using the initial model remain informative as these updates accumulate.

\subsection{The Linear Representation Hypothesis}
The linear representation hypothesis suggests that concepts and features within a model's internal states are organized as linear directions. This implies that one can extract and identify these concepts using simple, linear classifiers (probes). 

Features rotate or get scaled during training
The paper [2601.22012] Putting a Face to Forgetting: Continual Learning meets Mechanistic Interpretability shows how knowledge changes during CL training. It decomposes the change to a feature into two primitive transformations — rotation and scaling — and separates their consequences into two kinds:
Readout misalignment. Scaling or rotating a feature without updating the downstream readout makes it read a weaker/stronger or shifted signal. This is recoverable by realigning the readout (as long as the feature's capacity is intact).
Capacity degradation. The feature's allocated capacity drops, which is irrecoverable. This happens via:
overlap — a feature rotates toward another, increasing their inner product and forcing them to share capacity;
fading — a feature's norm shrinks, losing capacity and, in the limit of norm → 0, vanishing entirely. Fading turns out to be the dominant driver of forgetting in the paper’s setup.
