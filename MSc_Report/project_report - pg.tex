\begin{abstract}
    % TODO
Continual learning, the ability of AI systems to learn in real time from interactions with an environment, yields pre-deployment model's evaluations unreliable. This work focuses on the problem of emergent misalignment (EM), where fine-tuning on examples containing mistakes or insecure code can produce broad concerning behaviour unrelated to the tasks the network was trained on. This phenomenon occurs by a change in the model's embodied persona during conversations from helpful and benign assistant to evil or sycophantic roles.

Steering vectors representing these personas, named ``persona vectors'', have been shown to be a good tool for predicting future misalignment. However, it is still unclear how sequential fine-tuning changes the dynamics of EM and whether these predictive tools can still be applicable in a continual learning setting. This project attempts to answer these questions.

\end{abstract}
